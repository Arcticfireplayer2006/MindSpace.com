Going Unmanaged?

Going unmanaged is certainly an option, however with an unmanaged machine you become responsible for ensuring that the latest security and application patches are applied. Unmanaged machines must use Debian Linux.

All managed machines on our network will receive an installation of our account control panel software. Unmanaged machines will need to make other arrangements for remotely administering their servers.

Software

Unless otherwise requested, all servers will come with a clean installation of Debian Linux, with all of the tools you'd expect with it. From there, you can configure your server to fit your exact specifications.

With a managed Debian Linux server you'll receive powerful software like Meevah Merchant (a $595 value), Analog statistics, CVS version control, an Apache web server, a MySQL database server, PHP4, and much more - all pre-installed. Your server will also be set up for SSL secure server support and receive regular data backups.

Support

Our unmanaged server offerings include basic support in getting the server hardware up and running and on the network...and that's about it!

The level of support that you can expect to receive with a managed server really depends on which of our MindCatcher monitoring plans you select upon signing up.
